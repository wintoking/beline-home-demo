# 必达公寓云原生微信小程序演示

在微信开发者工具中导入当前目录，使用测试号或工具支持的游客模式。需要登录开发者工具；本工程无后端依赖，无须 npm 构建。若工具不接受游客 AppID，请选择自己的测试小程序 AppID，仅用于本地预览。

首页是住户工作区。“我的”可切换管家、商户及房间。管家首页点击房间办理入住、续租、换房、临时授权与退租，账单页模拟支付，服务页处理报修。所有数据只保存在本地，可重置。

浏览器版与原生版使用相同业务模型，但各自保存本地数据，不跨环境同步。未对接登录、支付、电子签、TTLock、蓝牙和服务端，不能用于实际运营。

演示日期固定为 2026-10-24，费率与合同文本均为示例。设备离线时授权与控制进入待同步。

## 设备安装演示

切换为管家后，在首页点击“新增设备”。支持门锁、电表、水表的编号登记、房间绑定、安装配置、失败重试和验收。未完成任务可以继续或取消；暂无未绑定房间时可显式添加一间演示房间。

验收前不写入已绑定设备，门锁验收不自动发放住户钥匙，表计底数作为计量起点。所有编号、联网和测试均为模拟，不申请蓝牙或摄像头权限，不调用真实 TTLock 接口。
